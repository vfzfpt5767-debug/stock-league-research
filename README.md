# テーマ別 銘柄リサーチ（日経STOCKリーグ 第27回 用）

グループで **テーマを決める → 銘柄を選ぶ → 発表資料を作る** ための、日本語の学習用Webページです。
GitHub Pages で公開し、URLを送ればグループの全員が見られます（検索エンジンには載らない設定）。

> このページは学習目的の資料であり、投資の助言ではありません。

## できること

| 画面 | 内容 |
|---|---|
| ホーム | 使い方、5つのテーマの概要、ルールの要点 |
| テーマのページ | 候補銘柄（各テーマ18〜26社）と「なぜこのテーマに関係するか」の一言・出典リンク、業種の内訳。スライド用PNG |
| 銘柄の比較表 | テーマ・業種・決算日、株価メモ（自分で入力した株価・100株の金額）、業績（EDINET）と株主総利回り。並べ替え・絞り込み、PNG／CSV保存 |
| 銘柄のページ | テーマとの関係、事業の説明、株価・チャートを見るための外部リンク、株価メモ、業績と株主総利回りのグラフ・EDINETの提出書類（EDINETのAPIキー登録後） |
| テーマ比較 | テーマごとの銘柄数・業種の数・業績の中央値の比較表とグラフ（どれが良いとは決めつけない） |
| ポートフォリオ試算 | 500万円・10〜20銘柄・手数料1.1％で株数を計算（株価は入力）、業種とテーマのかたより、過去の時点との比較（TOPIXは入力値）。**組み合わせと入力した株価はURLで共有** |
| 情報の探し方 | テーマごとの公式な情報源と検索キーワード、EDINETの提出書類一覧 |
| ルール | 日経STOCKリーグ第27回の公式ルールの要点と出典（確認できなかった点は「未確認」） |
| PNG保存 | 表やグラフを横長（1920×1080）の白背景の画像で保存。スライドにそのまま貼れる |

## 株価を自動表示していない理由

株価などの市場データは取引所などに権利があり、規約上問題なく自動で集めて公開ページに表示できるデータ源が見つかりませんでした
（2026年11月4日には IR BANK の利用規約が施行され、自動取得と再配布が禁止されたため、いったん集めたデータを削除しました）。
株価は STOCKリーグのバーチャル投資システムや証券会社のサイトで確認し、「株価メモ」やポートフォリオ試算に入力して使います。
くわしくは [DECISIONS.md](DECISIONS.md) と、サイトの「データについて」ページ。

## データの出どころ

- **金融庁 EDINET**（EDINETコードリスト・EDINET API、公共データ利用規約 PDL1.0）：業種・決算日、有価証券報告書の主要な経営指標（売上・純利益・ROE・1株配当・株主総利回りなど）
  - 決算の数字は、リポジトリの Secret に `EDINET_API_KEY` を登録したときだけ自動で取得します（[SETUP.md](SETUP.md)）
- **日経STOCKリーグ公式（man@bow）**：ルールの要約
- **テーマとの関係**：Wikipedia・各社の発表・報道など（各銘柄に出典リンク）

## 銘柄・テーマを追加・削除する（スマホのブラウザでもできます）

1. GitHub で [`config/stocks.csv`](config/stocks.csv) を開き、鉛筆マーク（Edit this file）を押す
2. 1行が「テーマ×銘柄」1件。列は `theme_id,code,name,reason,business,source_title,source_url,note`
   - `theme_id`：テーマのID（`resources` `decarbon` `raremetal` `semicon` `energy`）
   - `code`：4桁の証券コード（例 `7203`、`285A`）
   - `reason`：なぜこのテーマに関係するか（一言）
   - `source_url`：その根拠となるページのURL（`https://` から）
   - 文章にカンマ「,」を入れたいときは、その欄全体を `"` で囲む
3. 「Commit changes」で保存すると、数分〜十数分で自動的にデータが作り直され、サイトに反映されます
4. テーマを増やす・休ませるときは [`config/themes.csv`](config/themes.csv)（`enabled` を `0` にすると非表示）

書き方を間違えると「Actions」タブに赤い×が付き、どの行がおかしいかが表示されます。

## 自動更新

GitHub Actions（`.github/workflows/update-and-deploy.yml`）が毎週月曜 18:37（日本時間）ごろと、設定ファイルを変更したときに動き、
EDINET の会社情報（と、APIキーがあれば決算データ）を取り直して `docs/data/` に保存し、GitHub Pages に公開します。
相手のサイトに負担をかけないようアクセスの間隔をあけ、アクセスを拒否されたとき（HTTP 401/403 など）はその回のアクセスをやめます。

## 自分のパソコンで動かす（任意・上級者向け）

```bash
pip install -r requirements.txt
python -m pytest -q                 # テスト
python -m slr.build                 # データを作り直す（EDINET_API_KEY を設定すると決算データも）
python -m http.server -d docs 8000  # http://localhost:8000 で表示
```

## フォルダの中身

| 場所 | 中身 |
|---|---|
| `config/` | テーマ・銘柄の設定（CSV）、STOCKリーグのルール（`rules.json`） |
| `slr/` | データを集めて計算するプログラム（Python） |
| `docs/` | 公開されるWebページ（HTML/CSS/JavaScript）と、集めたデータ（`docs/data/`） |
| `tests/` | テスト |
| `DECISIONS.md` | 作るときに迷った点と、選んだ方針・理由 |
